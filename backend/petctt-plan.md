## 🔴 1단계: 즉시 수정 (버그/깨진 부분)

### 1-1. 젬 스튜디오 링크 수정
- **현재:** `http://localhost:3000` (로컬 주소로 외부 접속 불가)
- **해결:** 실제 URL로 변경하거나 Coming Soon 처리

### 1-2. 로그인 버튼 동작 없음
- **현재:** 상단 로그인 버튼 클릭 시 아무 반응 없음
- **해결:** 로그인 모달 팝업 연결 (AIRCTT 로그인 모달 코드 적용)

### 1-3. 쇼핑 버튼 동작 확인
- **현재:** 네비게이션 🛒 쇼핑 버튼 → 구름장터 섹션 이동 여부 불확실
- **해결:** 앵커 링크 정상 작동 확인

### 1-4. LIVE 준비 표시
- **현재:** 상단에 "LIVE 준비" 텍스트만 존재
- **해결:** 실제 상태 연동 또는 디자인 개선

## 🟡 2단계: 핵심 기능 구현 (백엔드 연결)

### 2-1. 회원가입/로그인 시스템
- **필요 작업:**
  - 구글 OAuth 연동 (Google Cloud Console 설정)
  - 카카오 OAuth 연동 (Kakao Developers 설정)
  - 네이버 OAuth 연동 (Naver Developers 설정)
  - 이메일/비밀번호 로그인 (JWT 토큰 기반)
- **백엔드:** `server/routes/auth.js` 구현
- **DB 테이블:** `users`, `refresh_tokens`
- **우선순위:** ★★★★★ (모든 기능의 기반)

### 2-2. 구름장터 매장 시스템
- **현재:** 하림펫 외부 링크 1개 + Coming Soon 2개
- **필요 작업:**
  - 매장 입점 신청 페이지
  - 매장 목록/검색 페이지
  - 매장 상세 페이지 (상품 목록)
  - 상품 등록/수정/삭제 (매장 관리자용)
  - 장바구니 + 주문
- **백엔드:** `server/routes/stores.js`, `server/routes/products.js`
- **DB 테이블:** `stores`, `products`, `orders`, `order_items`
- **우선순위:** ★★★★☆

### 2-3. 쿠폰톡톡 시스템
- **현재:** Coming Soon 상태
- **필요 작업:**
  - 쿠폰 목록 페이지 (매장별 쿠폰)
  - 쿠폰 잡기 3D 게임 (Three.js) — 기존 AIRCTT 코드 활용
  - 쿠폰 지갑 (보유 쿠폰 관리)
  - 쿠폰 사용 (구름장터 주문 시 적용)
- **백엔드:** `server/routes/coupons.js`, `server/routes/game.js`
- **DB 테이블:** `coupons`, `coupon_wallet`, `game_records`
- **우선순위:** ★★★☆☆

## 🟢 3단계: 기존 기능 고도화

### 3-1. 동물 통역 AI 연동
- **현재:** UI 완성, 마이크 버튼 있음
- **필요 작업:**
  - 음성 인식 API 연동 (Web Speech API 또는 외부 API)
  - AI 통역 모델 연결 (GPT 기반 동물 감정 해석)
  - 감정 분석 결과 실시간 표시 (불안/고통/흥분/안정/요구)
  - TTS로 통역 결과 읽어주기
- **우선순위:** ★★★★☆ (핵심 차별점)

### 3-2. 건강/생체분석 고도화
- **현재:** 카메라 UI + 고정 수치 표시
- **필요 작업:**
  - 카메라 접근 → 실제 영상 분석 연결
  - AI 기반 심박수/호흡/스트레스 추정 로직
  - 건강 기록 DB 저장 (히스토리 조회)
  - 하드웨어 센서 연동 (귀걸이/목걸이 센서 — 향후)
- **우선순위:** ★★★☆☆

### 3-3. 위치 추적 지도 연동
- **현재:** GPS 좌표 표시 UI만 있음
- **필요 작업:**
  - Google Maps 또는 Kakao Map API 연동
  - 실시간 위치 지도에 표시
  - 이동 경로 히스토리 시각화
  - 반려동물 프로필별 위치 관리
- **우선순위:** ★★★☆☆

### 3-4. 방송국 기능
- **현재:** 채널 목록 UI (클TV, 젬 스튜디오, 엔티 공방, 아미 라이브)
- **필요 작업:**
  - 실시간 스트리밍 연동 (WebRTC 또는 외부 서비스)
  - 채팅 기능
  - 방송 녹화/다시보기
- **우선순위:** ★★☆☆☆ (후순위)

### 3-5. 아미 AI 챗봇 고도화
