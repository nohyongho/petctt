## 🎯 작업 단계 (To-Be)

### Phase 1: 핵심 인프라 (Day 1) 🔴
> 로그인이 되어야 모든 게 시작된다!

**1-1. 도메인 라우팅 설정**
- Cloudflare Dashboard → petctt.com DNS
- Worker Route: `petctt.com/api/auth/*` → petctt-auth Worker
- CORS 설정 확인

**1-2. 프론트엔드 로그인 연결**
- auth/callback.html 페이지 생성 (토큰 수신)
- 로그인 버튼 클릭 → Worker OAuth 호출
- JWT 토큰 localStorage 저장
- 로그인 상태 UI 표시 (프로필 아이콘)

**1-3. 법률 페이지 (필수!)**
- privacy.html - 개인정보처리방침
- terms.html - 이용약관
