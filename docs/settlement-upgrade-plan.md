## P0 - 실운영 필수 (7개)

### P0-1. 정산 예정 금액 위젯 + 정산일
- [ ] 정산개요 상단에 다음 정산일 / 예상 지급액 위젯
- [ ] 정산 주기 설정 (주2회/주1회/월2회)
- [ ] 정산일 달력 뷰

### P0-2. 정산 상태 트래킹 3단계
- [ ] 집계중 -> 확정 -> 지급완료
- [ ] 정산 회차 개념 (2026-03 1회차, 2회차)
- [ ] 회차별 상태 배지
- [ ] 지급완료 시 일시/담당자 기록

### P0-3. 취소/환불 처리 + 귀책 구분
- [ ] 거래 상태에 취소/환불 추가
- [ ] 취소 유형: 고객/가맹점/플랫폼 귀책
- [ ] 귀책별 수수료 환급 자동 처리
- [ ] 부분취소 지원
- [ ] 취소 사유 입력

### P0-4. 수수료 유형별 명세
- [ ] 중개수수료 / PG수수료 / 광고비 / 배달비 / 기타
- [ ] 거래 등록 시 수수료 유형 선택
- [ ] 정산서에 유형별 소계
- [ ] 유형별 수수료율 각각 설정

### P0-5. 부가세(VAT) 처리
- [ ] 수수료 = 공급가액 + 부가세(10%) 자동 분리
- [ ] 정산개요에 부가세 합계
- [ ] CSV/정산서에 공급가액/부가세 컬럼
- [ ] 간이/일반 과세자 구분

### P0-6. 정산서 PDF 다운로드
- [ ] 월별/회차별 정산서 PDF 생성 (jsPDF)
- [ ] 기간/매출합계/수수료명세/부가세/실지급액
- [ ] 역할별 정산서 포맷
- [ ] 인쇄 최적화 CSS

### P0-7. 정산 계좌 등록/관리
- [ ] 총판/대리점/가맹점 계좌 정보 필드
- [ ] 은행명 / 계좌번호 / 예금주
- [ ] 계좌 변경 이력
- [ ] 계좌번호 마스킹 (****)
