핵심 파일들:

.env → DB 비밀번호만 수정하면 끝
database/schema.sql → 10개 테이블 (users, stores, products, coupons, coupon_wallet, orders, order_items, game_records, pets, refresh_tokens)
server/db.js → mysql2 연결 모듈
server/server.js → Express 서버 + 헬스체크
server/db-test.js → DB 연결 테스트 전용 스크립트
🔥 실행 순서 (PowerShell에서)
powershell
# 1. ZIP 압축 풀고 폴더 이동
cd C:\petctt-backend

# 2. .env 파일에서 DB_PASSWORD만 실제 비밀번호로 수정!

# 3. 패키지 설치
npm install

# 4. 테이블 생성
mysql -u petctt_user -p petctt < database/schema.sql

# 5. DB 연결 테스트
node server/db-test.js

# 6. 서버 실행
npm run dev
Step 5에서 ✅ 나오면 성공! 그 다음 http://localhost:5000/health 에서 "database": "connected" 확인하면 돼요.
